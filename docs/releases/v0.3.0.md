**ricercar 0.3.0** gives the app its own identity: a hi-fi listening room built around the signal path, rather than a streaming storefront.

## Downloads

| Your system | File | Install |
|---|---|---|
| Debian 12+, Ubuntu 22.04+, Mint, Pop!_OS, Zorin, elementary | `ricercar_0.3.0-1_amd64.deb` / `_arm64.deb` | `sudo apt install ./ricercar_*.deb` |
| Fedora, openSUSE, RHEL / Alma / Rocky 9+ | `ricercar-0.3.0-1.x86_64.rpm` / `.aarch64.rpm` | `sudo dnf install ./ricercar-*.rpm` |

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing`.

## What's new

- **Signal path always in view**: the chain (source → processing → output format → device) sits under the seek bar, green when bit-perfect, amber as soon as something alters the samples. One click opens every hop.
- **Listening header on Home**: what is playing (or what you played last), with its format and where it goes, plus Play / Open album.
- **Format column** on every track list: codec and resolution (`FLAC 24/96`), hi-res in gold.
- **Artist pages** laid out like sleeves on a shelf: covers, discography, most played, also appears on.
- **Hi-fi controls**: Play / Shuffle text buttons on album, artist and playlist pages; album tiles open on click, play on double-click, and the playing album wears an on-air chip.
- **Live search for internet radio** as you type; device name and ListenBrainz token save without pressing Enter.
- Settings rows are vertically aligned.

Full details of the 0.2 overhaul (engine, OpenHome, library, packaging) are in the [0.2.0 notes](https://github.com/ricercar-player/ricercar/releases/tag/v0.2.0).
