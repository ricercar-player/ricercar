**ricercar 0.2.0** is a ground-up overhaul: a full desktop app, an OpenHome renderer, and a hardened bit-perfect engine.

## Highlights

- **New desktop app**: home, album grid, album / artist / genre / playlist pages, search, internet radio, settings; full-screen now playing with synced lyrics; a queue you can drag to reorder; dark & light themes; English & French; tray icon, notifications, keyboard shortcuts.
- **Signal-path view**: every hop from file to DAC, with green for untouched and amber for altered. Bit-perfect is only claimed for untouched samples on a `hw:` device.
- **OpenHome renderer** alongside UPnP AV (Product, Playlist, Info, Time, Volume): the queue lives on the PC. **UPnP MediaServer** with a browsable hierarchy, search and range streaming.
- **Library v2**: incremental parallel indexing, accent-insensitive full-text search, favorites, play history, playlists (M3U), covers from Cover Art Archive, lyrics from `.lrc` files, tags or LRCLIB.
- **Scrobbling** to ListenBrainz and Last.fm with an offline queue; MPRIS with loop / shuffle / raise / quit.

## Audio engine fixes (important if you tried 0.1)

- ALSA output wrote through an API that only accepts 8-bit formats: **playback to real devices could not work in 0.1**. Fixed.
- 24-bit audio was misaligned for `S24_LE`, which would give noise on 24-bit DACs. The container is now negotiated losslessly (S16 / S24_3LE / S24 / S32).
- AIFF and 24-bit WAV decoded shifted. Fixed, with bit-exact tests.
- Hardware pause, device hot-switch, clean stop on unplug, ReplayGain with peak protection (off by default), seekable HTTP streams, ICY titles for radio, AAC and AIFF support.

## Network & security fixes

- SSDP used the wrong multicast group (239.2.55.52 instead of 239.255.255.250). Discovery should now work.
- The `/art` endpoint could be made to fetch arbitrary URLs (SSRF). It now serves library art only.
- Proper GENA property sets, initial events, SOAP / DIDL entity handling, distinct renderer / server UDNs.

## Packaging

`dist/arch/PKGBUILD`, a systemd user unit for headless boxes, an updated `.desktop` entry, and single-instance hand-off (`ricercar file.flac` plays in the running instance).

## Not yet verified

Real control points (BubbleUPnP, Kazoo, Symfonium…) and real DACs have not been reported yet. Please send compatibility reports, see [docs/CONTROLS.md](https://github.com/ricercar-player/ricercar/blob/v0.2.0/docs/CONTROLS.md).
