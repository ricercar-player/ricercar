**ricercar 0.3.1** is a solidity release: big libraries stay fluid, the app reopens as you left it, network settings apply without a restart, and you can see what your DAC accepts.

## Downloads

| Your system | File | Install |
|---|---|---|
| Debian 12+, Ubuntu 22.04+, Mint, Pop!_OS, Zorin, elementary | `ricercar_0.3.1-1_amd64.deb` / `_arm64.deb` | `sudo apt install ./ricercar_*.deb` |
| Fedora, openSUSE, RHEL / Alma / Rocky 9+ | `ricercar-0.3.1-1.x86_64.rpm` / `.aarch64.rpm` | `sudo dnf install ./ricercar-*.rpm` |

| Any distribution (portable) | `ricercar-0.3.1-x86_64.AppImage` / `-aarch64.AppImage` | `chmod +x ricercar-*.AppImage && ./ricercar-*.AppImage` |

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing`.

## What's new

- **Big libraries stay fluid.** Tested on 50 000 tracks: the Tracks page opens in ~70 ms instead of up to 0.8 s, search answers in under 50 ms, covers and the "playing" marker only touch the rows concerned, and the queue drawer is virtualized. Method and numbers are in [docs/perf.md](https://github.com/ricercar-player/ricercar/blob/v0.3.1/docs/perf.md).
- **Reopens as you left it**: window size (and maximized state), last page, album and track sorts, hi-res filter, queue drawer.
- **Network settings apply live**: rename the device or switch the renderer and the media server on or off without restarting. The two are now independent, and phone apps find the same device again.
- **DAC capabilities** in Settings → Audio output: unfold a `hw:` device to see the sample rates and containers it accepts, and which albums of your library it cannot play natively. Albums at a rate the active DAC refuses carry a "Not supported by the DAC" badge, and a refusal now says what the DAC does accept.
- **Diagnostic report** for compatibility issues: Settings → About → Copy diagnostic report (versions, devices, signal path, network, settings with secrets hidden, recent log lines). Logs now also go to `~/.local/state/ricercar/ricercar.log`. A "Compatibility report" issue template asks for it.

**From source:** `cargo build --release` (see the README for per-distro dependencies).
