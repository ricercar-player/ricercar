**ricercar 0.5.0** makes plugin catalogues feel at home: their playlists sit with yours, their picks show on Home, search sorts everything by kind, and Bluetooth headphones appear in the outputs.

## Downloads

| Your system | File | Install |
|---|---|---|
| Debian 12+, Ubuntu 22.04+, Mint, Pop!_OS, Zorin, elementary | `ricercar_0.5.0-1_amd64.deb` / `_arm64.deb` | `sudo apt install ./ricercar_*.deb` |
| Fedora, openSUSE, RHEL / Alma / Rocky 9+ | `ricercar-0.5.0-1.x86_64.rpm` / `.aarch64.rpm` | `sudo dnf install ./ricercar-*.rpm` |
| Arch, Manjaro, EndeavourOS, CachyOS, Omarchy | `ricercar-0.5.0-1-x86_64.pkg.tar.zst` | `sudo pacman -U ricercar-*.pkg.tar.zst` |
| Any distribution (portable) | `ricercar-0.5.0-x86_64.AppImage` / `-aarch64.AppImage` | `chmod +x ricercar-*.AppImage && ./ricercar-*.AppImage` |
| Any distribution (plain binaries) | `ricercar-0.5.0-linux-x86_64.tar.gz` / `-aarch64` | unpack, run `bin/ricercar` |

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing`.

## What's new

- **Plugins with a library leave the sidebar.** A plugin that shares its library no longer keeps a block of its own: its playlists join your **Playlists** list, marked with its name, and its picks (new releases, editorial selections) become shelves on **Home**. Plugins without a library keep their sidebar section as before.
- **Search by kind.** Results now include playlists, yours and those of your plugins, and a filter under the title narrows them to artists, tracks (then all of them), albums or playlists.
- **Recently played on Home**, from every source: plugin tracks are now counted when you play them, and Home lists the last tracks you played with their source badge.
- **Bluetooth and other PipeWire outputs.** Headphones and speakers that only exist in PipeWire are listed in the outputs, marked as shared (not bit-perfect), next to the bit-perfect `hw:` devices.
- **Choose the language.** Settings → Appearance → Language: System, English or Français, applied at once.
- **Smoother touchpad scrolling.** A two-finger swipe no longer runs away; mouse wheels keep their smooth scroll.
- **Fixes:** one notification per track (plugin tracks showed two); e-mail addresses are masked in the diagnostic report's log lines.
- **For plugin authors:** two optional additions to the protocol, `library.playlists` and a `home` list in `browse.root` (see [docs/plugins.md](https://github.com/ricercar-player/ricercar/blob/v0.5.0/docs/plugins.md)). Plugins written for 0.4 keep working unchanged.

> Plugins are written by third parties and are not reviewed by the ricercar project. They run with your permissions: install only plugins you trust, and check that they respect the terms of the service they use.

Coming from 0.4.0? See also the [0.4.1 notes](https://github.com/ricercar-player/ricercar/releases/tag/v0.4.1): plugin libraries in the main pages, one search for everything, update notices.

**From source:** `cargo build --release` (see the README for per-distro dependencies).
