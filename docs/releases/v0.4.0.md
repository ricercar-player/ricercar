**ricercar 0.4.0** opens the player to **source plugins**: catalogues brought by separate programs, installed from a community hub, while playback stays bit-perfect and every hop shows in the signal path.

## What's new

- **Source plugins.** A plugin is a separate program, in any language, that speaks a small JSON-RPC protocol on stdio ([docs/plugins.md](https://github.com/ricercar-player/ricercar/blob/v0.4.0/docs/plugins.md)). It brings a catalogue (browse, search, favourites) and hands ricercar a URL for each track. ricercar fetches, decodes and plays it like any stream, so output stays bit-perfect when the track allows it. A crashing or slow plugin never takes the player down: it is restarted with backoff.
- **Plugins page.** Install plugins from the [community hub](https://github.com/ricercar-player/ricercar-plugins), update them, sign in and out, or turn them off, all without a restart. The hub only lists links to authors' repositories and binaries. ricercar checks each download against the SHA-256 in the listing and asks before installing anything.
- **Sign-in in your browser.** No password ever goes through ricercar. The plugin's sign-in address opens in your browser, and also shows as a QR code for signing in on another device.
- **Plugin catalogues in the app.** Sidebar sections for each signed-in plugin, a browse page for its albums and playlists, and a search tab per plugin. Plugin tracks can go into your local playlists, and the signal path starts with "Source: <plugin>".
- **For developers:** the protocol, a reference plugin (`ricercar-demo-plugin`) and tests on the null sink cover sign-in, gapless preloading, expiring URLs and crash recovery.

> Plugins are written by third parties and are not reviewed by the ricercar project. They run with your permissions: install only plugins you trust, and check that they respect the terms of the service they use.

Also in this release, from 0.3.1: fluid 50 000-track libraries, the window reopening as you left it, network settings applied live, the DAC capabilities panel and the diagnostic report. See the [0.3.1 notes](https://github.com/ricercar-player/ricercar/releases/tag/v0.3.1).
